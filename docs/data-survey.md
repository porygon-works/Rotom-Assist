## 2. 計算の確認結果
| 条件 | 結果 |
|---|---|
| SV（Lv50）無振り: ミミッキュのじゃれつく → ガブリアス | 98-116（53.5〜63.3%）確定2発 |
| チャンピオンズ SP0: 同上 | 98-116（53.5〜63.3%）確定2発（同じ） |
| SV いじっぱり A252 | 138-164（75.4〜89.6%）確定2発 |
| チャンピオンズ いじっぱり A32（SP） | 138-164（75.4〜89.6%）確定2発（同じ） |
| チャンピオンズ ひかえめ C32 メガリザードンY のかえんほうしゃ → ドドゲザン | 224-266（128〜152%）確定1発 |
| チャンピオンズ ようき S32 ガブリアスの素早さ | 169（SV の最速と同じ） |

- SP 32 は SV の努力値 252 と同じ実数値になる。ほかの SP（例: 1〜31）の換算は、ライブラリの式（HP = 種族値 + SP + 75、ほか = (種族値 + SP + 20) × 性格補正）に従う
- **Showdown の計算機の画面との突き合わせ、ゲーム内の実測とのズレ確認は未実施**

## 3. チャンピオンズにいないポケモン（テストの質問文に影響）
- ハバタクカミ（Flutter Mane）、テツノブジン（Iron Valiant）などのパラドックスはいない
- 例: モロバレル（Amoonguss）、トゲキッス（Togekiss）もいない
- 確認できたもの: ガブリアス、ミミッキュ、ブリジュラス、サーフゴー、ドドゲザン、ドラパルト、カイリュー、リザードン（メガY）、ハッサム、サーナイト、ニンフィア、ゲンガー、サザンドラ、バンギラス、ウルガモス、ウォッシュロトム、ガオガエン など

## 4. 設計への影響
1. **計算は `@smogon/calc` の第0世代を使う。** 努力値の代わりに SP（各 0〜32、合計 66）で指定する
2. **覚える技・全特性・日本語名は、Showdown 本体と PokeAPI から事前に変換して、アプリ用のデータを作る。** 更新は手動（シーズンやバージョンの更新時）
3. **よくある型は、まず手入力の「型の一覧」で始める。** Smogon の統計が取れることを確認できたら、自動で作る方式を検討する
4. データの出典（Showdown、PokeAPI など）を、アプリと文書に表示する
