## 2. 試し方
- **手元**: `npm install` → `GEMINI_API_KEY` と `GROQ_API_KEY` を環境変数に入れる → `npm run dev` → http://localhost:3000
- **Vercel**: Settings → Environment Variables に `GEMINI_API_KEY`・`GROQ_API_KEY` を登録して再デプロイ（**未登録だと「AI の設定がまだロト」と返る**）
- 話し方の例:
  - 「HB振りエンペルトのHP120残ってるんだけど、A特化ガブのじしん耐える？」→「耐えられないロト。確定1発ロト！ 85から101パーセントロト。残りHP120で計算したロト」
  - 「S二段階上昇のイダイトウってメガルカリオZがどこまですばやさ振ってたら負ける？」→「メガルカリオZが補正なしでSP26以上、補正ありでSP9以上なら、イダイトウが抜かれるロト」
  - 続けて「じゃあステロ込みだったら？」のように聞くと、前の質問を引き継ぐ
